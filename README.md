# Gator

A command-line RSS feed aggregator written in Go. Register users, add feeds, follow the ones you care about, and pull the latest posts — all from your terminal, backed by PostgreSQL.

## Features

- User registration and login with persistent sessions
- Add RSS feeds and follow/unfollow them per user
- List all feeds and the user who added them
- Fetch and parse remote RSS feeds
- PostgreSQL storage with type-safe queries generated by [sqlc](https://sqlc.dev)

## Requirements

- [Go](https://go.dev/dl/) 1.26+
- [PostgreSQL](https://www.postgresql.org/) 14+

## Installation

```bash
go install github.com/othmantabeche/RDF-site-summary.git@latest
```

Or build from source:

```bash
git clone https://github.com/othmantabeche/RDF-site-summary.git
cd RDF-site-summary
go build -o gator .
```

## Configuration

Gator reads its configuration from `~/.gatorconfig.json`. Create the file with your PostgreSQL connection string:

```json
{
  "db_url": "postgres://user:password@localhost:5432/gator?sslmode=disable",
  "current_user_name": ""
}
```

The `current_user_name` field is managed automatically when you register or log in.

## Database Setup

Apply the schema migrations in `sql/schema` to your PostgreSQL database (for example with [goose](https://github.com/pressly/goose)):

```bash
goose -dir sql/schema postgres "$DB_URL" up
```

## Usage

```bash
gator register <name>      # Create a new user and log in
gator login <name>         # Switch to an existing user
gator users                # List all users (marks the current one)
gator addfeed <name> <url> # Add a feed and follow it
gator feeds                # List all feeds
gator follow <url>         # Follow an existing feed
gator following            # List the feeds you follow
gator agg                  # Fetch and print the latest feed items
gator reset                # Wipe all users from the database
```
